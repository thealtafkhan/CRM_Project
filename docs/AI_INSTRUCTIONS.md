# AI DEVELOPMENT INSTRUCTIONS — AcxiomCRM

## 1. Prime Directive
Every AI agent or software engineer working on AcxiomCRM must adhere strictly to the **AcxiomCRM Functional & Technical Project Documentation Specification**. Speed must never be prioritized over completeness, security, or requirement compliance.

---

## 2. Non-Negotiable Operational Rules
1. **No Mock / Placeholder Implementations**: Features must be backed by genuine database entities, EF Core configurations, controller logic, and Razor views.
2. **Never Bypass Validations**: Both client-side and server-side validations are mandatory.
3. **Never Hardcode Secrets**: Passwords and keys must always be read from configuration.
4. **Synchronize Documentation**: Update `TASK_TRACKER.md` and `CHANGELOG.md` upon completing any development task.
5. **Phase-by-Phase Discipline**: Never begin coding the next phase without verifying the preceding phase and presenting completion proof.
